**Подключите AI-ассистента (Claude, Qwen, Kimi, Reasonix) к 1С:Предприятию и работайте с базой как с источником данных через диалог.**

## Что это

`1c-mcp-bridge` — это сервер [Model Context Protocol](https://modelcontextprotocol.io/),
который подключает AI-ассистентов (Claude Desktop, Qwen Desktop, Kimi Desktop, Reasonix) напрямую
к одной или нескольким информационным базам 1С через COM-коннектор. AI-ассистент получает
пять инструментов (`execute_query`, `describe_object`, `list_metadata`, `get_object_by_ref`,
`list_databases`) и работает с базой так же, как с обычным источником данных:
формулирует запрос на языке запросов 1С, исполняет, возвращает результат, считает
аналитику.

```
┌───────────────────────┐   stdio    ┌──────────────────┐    COM    ┌──────────────────┐
│  Claude / Qwen / Kimi / Reasonix │ ──────► │ MCP-сервер (Py)  │ ────────► │ 1С:Предприятие   │
└───────────────────────┘            └──────────────────┘           └──────────────────┘
```

## Кому это нужно

* **Бухгалтеру / финансовому аналитику**, который хочет сказать «покажи топ-10
  покупателей за апрель» и получить таблицу.
* **Разработчику 1С**, которому удобно проверить структуру конфигурации без
  захода в Конфигуратор.
* **Команде с несколькими базами** (УТ + БП + ЗУП) — AI-ассистент видит все настроенные
  базы сразу, для каждой можно дать осмысленное описание, и он сам выбирает
  правильную для конкретного вопроса.

## Что умеет

| Среда | Поддержка |
|---|---|
| Платформа 1С:Предприятие | 8.2, 8.3, 8.5 |
| Файловая база (.1CD) | да |
| Клиент-серверная база (1С-сервер) | да |
| Аутентификация Windows (OS-auth) | да |
| Аутентификация средствами 1С | да |
| Несколько баз одновременно | да |
| ОС | Windows 10 / 11 / Server 2016+ |

> **Только чтение.** В версии v0.2.0 все операции строго read-only —
> `execute_query` использует объект `Запрос`, который не модифицирует данные.
> Запись и редактирование запланированы на v0.3.0 (см. [Roadmap](#roadmap)).

## Подключение к Qwen Desktop

Qwen Desktop разрешает только `npx`/`uvx` для stdio MCP-серверов.  
Используйте **HTTP-сервер** — он запускается без окна консоли.

1. Запустите ярлык **«1C Bridge (HTTP-сервер для Qwen)»** из меню Пуск.
   Сервер запустится в фоне (без окна). Остановить — Диспетчер задач → `python.exe`.
2. В Qwen Desktop: Настройки → MCP → Добавить:
   - Тип: **StreamableHTTP**
   - URL: `http://127.0.0.1:8000/mcp`

> Для автозапуска при входе в систему — добавьте ярлык в `shell:startup`
> или настройте Планировщик заданий Windows.

## Несколько баз и заметки для AI (v0.3.0)

Если у вас несколько баз — после установки запустите **1C Bridge Manager**
из меню Пуск. Он позволяет:

* Добавить любое количество баз с разными платформами (8.2/8.3/8.5).
* Назначить базу по умолчанию (используется когда AI не указывает явно).
* **Заметки для AI** — большое поле, где можно описать что в этой базе
  можно найти. Эти заметки попадают в `tools/list` и AI-ассистент видит их **до**
  первого вопроса. Например: *«В этой базе ведётся управленческий учет, оптовая
  торговля, закупки, учёт финансов. Учёт розничных продаж ведётся в Розница 1.0.»*
  → AI сам поймёт что для вопросов про розницу надо идти в другую базу.
* Переключатель «Использовать эту базу» — снимаете галку, и AI её не видит,
  но запись остаётся (удобно для переключения тест/прод).

## Безопасность

* **Только чтение.** Запись в базу не реализована. Для аналитики этого достаточно.
* **Локальное хранение.** Учётные данные базы хранятся в
  `%PROGRAMDATA%\1cMcpBridge\databases.json` и никогда не уходят за пределы
  компьютера. Anthropic видит только текст запроса и табличный результат —
  ровно то, что вы решите отправить как часть вопроса AI-ассистенту.
* **Отдельный пользователь 1С.** Рекомендуется завести в 1С пользователя
  «AI-аналитик» с правами только на просмотр нужных объектов.
* **Изоляция тест/прод через переключатель `enabled`** — для опасных
  экспериментов держите рабочие базы отключёнными, включайте только тестовые.
* **Пароли 1С** хранятся в `%PROGRAMDATA%\1cMcpBridge\databases.json`. Файл защищён ACL — доступ только текущему пользователю, SYSTEM и администраторам. По возможности используйте **аутентификацию Windows** вместо логина/пароля (DPAPI запланирован на v0.5.0).
* **HTTP-сервер** (для Qwen) слушает только `127.0.0.1` — доступ из сети закрыт. Без флага `--insecure-host` привязаться к внешнему интерфейсу нельзя. Токенная аутентификация запланирована на v0.5.0.
* **Данные запросов** передаются выбранному AI-провайдеру. Результаты запросов и описания баз видны модели.
* **Ограничения**: длина запроса (10K символов), число колонок (200), параметров (50), строк ответа (10K).

## Сборка из исходников

Нужны: Windows, [Inno Setup 6](https://jrsoftware.org/isdl.php), Python 3.12.

```powershell
git clone https://github.com/dimax27/1c-mcp-bridge.git
cd 1c-mcp-bridge
$env:APP_VERSION = '0.4.3'
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" installer\setup.iss
# Готовый .exe появится в .\dist\
```

Или просто нажать `Run workflow` на вкладке Actions — GitHub соберёт всё сам.

## Диагностика проблем

Если что-то не работает — запустите диагностику:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Program Files\1cMcpBridge\installer\detect_1c.ps1"
```

Покажет какие платформы 1С нашлись, зарегистрированы ли коннекторы, есть ли
Python и MCP-клиенты.

Логи установки лежат в `C:\Program Files\1cMcpBridge\installer\install.log`.
Логи работы MCP-сервера:
  • Claude Desktop: `%APPDATA%\Claude\logs\mcp-server-1c-bridge.log`
  • Qwen Desktop:  `%APPDATA%\Qwen\logs\`
  • Kimi Desktop:  `%APPDATA%\Kimi\logs\`

Подробнее — см. [docs/troubleshooting.md](docs/troubleshooting.md).
